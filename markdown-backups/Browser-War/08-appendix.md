## 8.1 按场景选浏览器

读完前面七章，你对浏览器的格局、隐私问题、商业模式都有了了解。但最终还是要落到一个实际问题：**我该用哪个？**

没有"最好的浏览器"——只有最适合你当前场景的。

### 8.1.1 日常浏览（注重隐私）

**首选：Brave**

理由：开箱即用的广告拦截和指纹防护，Chrome 扩展全兼容（因为同是 Chromium），几乎零配置成本。你不需要装任何插件、不需要改任何设置，打开就比 Chrome 安全。

适合：不想折腾但又想比 Chrome 好一点的人。

### 8.1.2 日常浏览（注重兼容性和生态）

**首选：Chrome + uBlock Origin**

理由：兼容性最好（毕竟 65% 的人在用，网站都优先适配它），扩展生态最丰富，DevTools 最强。但**务必**安装 uBlock Origin——裸奔的 Chrome 是追踪者的天堂。

适合：已经深度依赖 Chrome 生态（书签、密码、同步）不想迁移的人。

### 8.1.3 开发和调试

**主力：Chrome**（DevTools 生态最完善，Lighthouse、Performance 面板、Network 面板都是行业标准）

**辅助：Firefox**（独立引擎，用于跨引擎兼容性测试。它的 CSS Grid/Flexbox 调试工具比 Chrome 好用）

### 8.1.4 企业/办公环境

**首选：Edge**

理由：和 Microsoft 365、Azure AD、Intune 深度集成，IT 管理方便。Copilot 集成对办公场景有实际价值（总结文档、对比方案）。

### 8.1.5 极端隐私需求

**首选：Tor Browser 或 Mullvad Browser**

理由：最强的匿名性——流量经过多层加密和中继，网站几乎无法追踪你。但代价是速度很慢（因为流量要绕好几个节点），而且很多网站会拒绝 Tor 的访问。

适合：记者、活动人士、或者有特殊隐私需求的人。日常使用不推荐。

### 8.1.6 Apple 生态用户

**首选：Safari**

理由：第二章详细讲过了——续航好 3-4 小时、内存占用低 30-50%、隐私保护默认开启、和 Apple 设备无缝集成（Handoff、iCloud 标签页、Apple Pay）。

iPhone/iPad 上用什么浏览器其实无所谓——iOS 强制所有浏览器使用 WebKit 引擎，区别只在 UI。

### 8.1.7 AI 搜索重度用户

**首选：Comet（Perplexity 浏览器）**

理由：第七章讲过了——AI 搜索和浏览器无缝合一，不需要在浏览器和 AI 工具之间来回切换。Chrome 扩展全兼容，迁移成本低。


## 8.2 必装扩展

无论你用什么浏览器（Chromium 系或 Firefox），这几个扩展值得考虑：

| 扩展 | 做什么 | 为什么推荐 | 支持 |
|------|--------|-----------|------|
| **uBlock Origin** | 广告和追踪拦截 | 开源、无商业利益、不收集数据、效果最好 | Firefox, Chrome, Edge |
| **Bitwarden** | 密码管理器 | 开源、免费版够用、跨平台同步 | 全平台 |
| **Consent-O-Matic** | 自动处理 Cookie 弹窗 | 按你的偏好自动拒绝非必要 Cookie | Firefox, Chrome, Edge |

**关于扩展的一个提醒**：每个扩展都能读取你访问的网页内容。装得越多，攻击面越大。只装你真正需要的，定期审查已安装的扩展，删除不用的。


## 8.3 安全设置速查

不管你用哪个浏览器，花 5 分钟做这些一次性设置：

### 8.3.1 Chrome

```
设置 → 隐私和安全 → 第三方 Cookie → 阻止第三方 Cookie
设置 → 隐私和安全 → 安全 → 使用安全 DNS → 开启（选 Cloudflare 1.1.1.1）
设置 → 隐私和安全 → 广告隐私 → 全部关闭
设置 → 隐私和安全 → 安全 → 始终使用安全连接 → 开启
```

### 8.3.2 Firefox

```
设置 → 隐私与安全 → 增强型追踪保护 → 严格
设置 → 隐私与安全 → DNS over HTTPS → 最大保护
设置 → 隐私与安全 → HTTPS-Only 模式 → 在所有窗口中启用
```

### 8.3.3 Brave

Brave 默认已开启大部分保护（广告拦截、指纹防护、第三方 Cookie 阻止），几乎不需要额外配置。你可以在 `brave://settings/shields` 里查看和调整防护级别。

### 8.3.4 Safari

```
设置 → Safari → 隐私与安全 → 阻止跨站追踪 → 开启（默认已开启）
设置 → Safari → 隐私与安全 → 隐藏 IP 地址 → 对追踪器隐藏
```


## 8.4 检测你的隐私状态

想知道你的浏览器有多"暴露"？访问这些工具：

- **Cover Your Tracks**（`coveryourtracks.eff.org`）：EFF 的工具，检测你的浏览器指纹唯一性和追踪防护效果
- **BrowserLeaks**（`browserleaks.com`）：详细展示你的浏览器泄露了哪些信息（IP、WebRTC、Canvas、字体等）
- **Permission.site**（`permission.site`）：测试你的浏览器对各种权限请求（摄像头、麦克风、位置）的默认行为

建议：用你的日常浏览器访问 Cover Your Tracks，看看结果。如果显示"你的浏览器指纹是唯一的"，说明你很容易被追踪。然后换 Brave 或配置好的 Firefox 再测一次，对比差异。


## 8.5 最后的话

浏览器是你每天使用时间最长的软件之一。它是你和整个互联网之间的唯一接口。选择什么浏览器、如何配置它，直接决定了你的在线体验、隐私水平和安全程度。

希望读完这本书后，你不再只是一个被动的浏览器用户，而是一个理解浏览器如何工作、知道背后利益关系、能做出明智选择的知情用户。

互联网是人类最伟大的发明之一。浏览器是我们探索这个发明的窗口。让我们一起守护这扇窗口的开放和多样性。
