## 核心结论

DNS 查询通常一问一答、报文极小（< 512 字节），UDP 无需三次握手，延迟最低。

## 什么时候用 TCP

- 响应超过 512 字节（如 DNSSEC、大量记录）时，服务器置 TC 标志，客户端用 TCP 重试
- 区域传送（AXFR）直接走 TCP

:::callout 一句话版本
UDP 是默认快路径，TCP 是兜底大通道。
:::
