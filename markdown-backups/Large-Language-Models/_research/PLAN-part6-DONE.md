## 章节大纲（暂定 6–7 章）

### 第 1 章：美国三巨头的路线分野
OpenAI（GPT-5.x 谱系、router 统一架构、Stargate 算力叙事）、Anthropic（Claude 层级 Haiku<Sonnet<Opus<Fable/Mythos，宪法 AI 路线、2026-06 出口管制暂停又恢复的插曲）、Google（Gemini 3.x + Deep Think、TPU 自研全栈优势）。主线：三家的技术押注差异如何对应各自的商业模式差异（订阅 vs API vs 云生态捆绑）。

### 第 2 章：开放权重阵营——中国的选择
DeepSeek（V3→R1→V3.x→V4 的完整弧线，"性价比奇迹"背后的约束逻辑）、Qwen（全谱系覆盖策略、GSPO）、Kimi（K2→K3 的架构豪赌）、GLM/智谱、MiniMax（M1→M2 回退→M3 的路线反复，绝佳的"没有共识"案例）、字节/腾讯/阶跃/百度简述。主线：为什么"开放权重"成了中国大模型公司的主流打法（不是道德选择，是竞争策略——蒸馏防御、生态卡位、出海合规）。

### 第 3 章：模型谱系图——谁是谁的孩子
可视化/表格呈现"基模→衍生模型"的家族树（呼应第一卷 ch8 的"基模与版本语义"）。每家的换代节奏对比；哪些是同基模的兄弟；行业平均的"从基模到成熟产品"周期。这章适合做一张大表或时间轴图。

### 第 4 章：算力与地缘——芯片、出口管制与国产替代
在 P5 ch1"中国算力"一节基础上扩展成完整产业叙事：出口管制的政策博弈史、NVIDIA 的市场地位、国产芯片（昇腾/寒武纪/摩尔线程/海光）的产业化进度、"模型公司反向定义硬件标准"现象、数据中心电力瓶颈的地缘维度（谁能拿到电、谁拿不到）。

### 第 5 章：商业模式与钱从哪来
训练成本 vs 融资规模 vs 营收的真实比例；API 定价战（P5 ch3 已给出价格表，这里做商业逻辑分析：谁在补贴、能补贴多久）；订阅 vs API vs 开源+服务 三种商业模式对比；Agent 经济对定价结构的冲击（P5 已提过 token 消耗暴涨，这里讲它如何重塑收入模型）。

### 第 6 章（收官）：2026 年中场审视 & 全书回望
- 当下最大的不确定性（scaling 到头了吗——P2 已埋伏笔；开源能追上闭源多久；下一次架构/训练范式跃迁可能在哪）。
