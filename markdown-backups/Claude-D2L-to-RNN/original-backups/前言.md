# 前言

这个深度学习讲义系列是由Claude的Sonnet4.6和Opus4.6模型进行编写的，第一至第八章编写于2026年3月15日，第九、十章和强化学习章节编写于2026年3月17日。

全章节由我逐行阅读，自学后发布，对于一些初稿不明确/不够详细的内容，我用 `Mav’s tips：` 进行了注释讲解。

章节后面的习题仅供参考，只能算是一个快速的检测与复盘。

本书面向初学者，我们仅假设读者具有基础的数学与Python知识，对一些可能让读者感到困惑的地方也进行了说明。尽管我尽可能让这里面的知识对初学者友好，书中仍不可避免地会出现一些超前的知识。初次阅读可能感到困惑——你可以小小跳过这些部分，或者把重心放在讲述的重点，而不是部分没有学过的代码。使用AI来辅助学习，讲解这些知识点也是我们所建议的。
