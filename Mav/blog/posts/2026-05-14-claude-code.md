今天花了一整天研究 Claude Code，让 Claude 自己写了一本入门指南。讲解缓存机制、权限系统、子代理架构，感觉对 Claude Code 辅助编程的理解上了一个台阶。

最大的感受是：这不是一个"帮你写代码"的工具，而是一个"和你一起工作"的 agent。我明白了网页版的 AI 和真正意义上的 agent 有什么差距，功能不同，掌握的能力也大有不同。

指南放在[知识库](/knowledge/claude-code/index.html)里了，有兴趣可以看看。
