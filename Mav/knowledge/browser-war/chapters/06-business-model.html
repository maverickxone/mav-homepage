浏览器背后的公司与商业模式

6.1 浏览器是入口，不是产品

6.1.1 为什么浏览器都是免费的

你有没有想过一个问题：浏览器这么复杂的软件（Chromium 有 3500 万行代码，需要数百名工程师维护），为什么所有主流浏览器都是免费的？

答案是：浏览器本身不是产品，而是通往真正产品的入口。

类比一下：超市的购物车是免费的，因为超市靠你买的东西赚钱，不靠购物车。浏览器也是一样——它是你接触互联网服务的"购物车"，真正赚钱的是你通过浏览器使用的那些服务。

不同公司做浏览器的动机完全不同：

公司 浏览器 做浏览器的真正目的
Google Chrome 确保用户使用 Google 搜索和服务 → 广告收入
Apple Safari 锁定用户在 Apple 生态中 → 硬件销售
Microsoft Edge 推广 Bing 搜索和 Microsoft 365 → 云服务收入
Mozilla Firefox 使命驱动（保持互联网开放） → 搜索引擎分成
Brave Brave 重新定义广告模式 → BAT 代币生态

6.1.2 默认搜索引擎：浏览器最值钱的"位置"

浏览器里最值钱的东西不是任何功能，而是默认搜索引擎的位置。

当你在地址栏输入一个搜索词按回车，它会被发送到默认搜索引擎。大多数用户从不更改默认设置——这意味着谁控制了默认搜索引擎，谁就控制了用户的搜索流量。

搜索流量 = 广告收入。这就是为什么 Google 每年向 Apple 支付约 200 亿美元，只为让 Google 搜索成为 Safari 的默认搜索引擎。

这也是 2025 年 DOJ 反垄断案的核心：Google 通过这些排他性协议维持了搜索垄断。法官最终禁止了这类排他合同，但允许 Google 继续竞标默认位置（只是不能要求"只能是 Google"）。

6.2 Google Chrome：广告帝国的基石

6.2.1 Chrome 的商业逻辑

Google（Alphabet）2025 年的总收入超过 4000 亿美元，其中约 75-80% 来自广告业务。Google 搜索广告一项就贡献了超过 2000 亿美元。

Chrome 在这个商业模式中扮演什么角色？

用户使用 Chrome
    │
    ├── 默认搜索引擎是 Google → 搜索广告收入
    │
    ├── 登录 Google 账号 → 跨设备数据同步 → 更精准的广告定向
    │
    ├── 使用 Google 服务（Gmail, YouTube, Maps）→ 更多广告展示机会
    │
    ├── 浏览数据收集 → 用户画像 → 广告定向优化
    │
    └── 控制 Web 标准走向 → 确保 Google 服务始终有最好的体验

Chrome 本身不直接产生收入，但它是整个广告生态的"管道"。没有 Chrome，Google 的广告业务不会消失，但会失去对用户入口的控制权。

6.2.2 数据收集

Chrome 收集的用户数据包括：

  • 浏览历史：你访问了哪些网站（如果登录了 Google 账号并开启了同步）
  • 搜索历史：你搜索了什么
  • 使用统计：你使用了哪些功能、遇到了哪些错误
  • 自动填充数据：你的地址、电话、信用卡信息（加密存储）
  • 位置数据：如果允许了位置权限

Google 声称这些数据用于"改善用户体验"，但它们同时也被用于广告定向。这就是为什么你在 Chrome 里搜索了"跑步鞋"，然后在 YouTube 上看到跑步鞋广告。

6.2.3 Chrome 的"免费"代价

一个流行的说法是："如果你不是客户，你就是产品。"

Chrome 是免费的，但你用你的注意力和数据"付费"了。Google 把你的注意力卖给广告商，这就是 Chrome 的商业模式。

这不一定是"邪恶"的——Google 确实提供了优秀的产品和服务。但理解这个商业模式很重要，因为它解释了 Google 的很多决策：

  • 为什么 Chrome 不阻止第三方 Cookie？因为广告定向需要它。
  • 为什么 Manifest V3 限制广告拦截器？因为广告是 Google 的命脉。
  • 为什么 Chrome 不实现指纹防护？因为指纹追踪对广告行业有价值。

6.3 Apple Safari：生态锁定的工具

6.3.1 Apple 的商业模式

Apple 和 Google 的商业模式截然不同：

  • Google：靠广告赚钱，产品免费，用户数据是核心资产
  • Apple：靠硬件赚钱，隐私是卖点，用户数据不是主要收入来源

这就是为什么 Apple 在隐私保护上比 Google 积极得多——对 Apple 来说，保护用户隐私不会损害它的核心业务（卖 iPhone），反而是一个差异化的营销卖点。

Safari 在 Apple 的商业版图中扮演的角色：

  1. 生态锁定：Safari 和 iCloud、Apple Pay、Handoff 等功能深度集成。用 Safari 的体验在 Apple 设备上最好，这让用户更难离开 Apple 生态。
  2. 搜索引擎收入：Google 每年向 Apple 支付约 200 亿美元的默认搜索费用。这是 Apple 服务收入的重要组成部分。
  3. 隐私营销：Safari 的隐私功能（ITP、智能追踪防护）是 Apple "隐私是人权" 营销策略的一部分。

6.3.2 iOS 的浏览器垄断

Apple 有一个独特的优势：在 iOS 上，所有浏览器都必须使用 WebKit 引擎。这意味着：

  • iPhone 上的 Chrome 本质上是一个 WebKit 的壳，不是真正的 Chrome
  • iPhone 上的 Firefox 也是 WebKit 的壳
  • Apple 通过控制 iOS 上唯一允许的引擎，间接控制了移动端 Web 的能力边界

这个政策正在受到挑战。欧盟的 DMA（数字市场法案）要求 Apple 在欧盟地区允许第三方浏览器引擎。如果执行到位，这将是移动浏览器市场的一次重大变革。

6.3.3 Apple 的矛盾

Apple 在隐私问题上的立场并非完全无私：

  • Apple 一边宣传"保护用户隐私"，一边每年收 Google 200 亿美元让 Google 成为默认搜索引擎——而 Google 正是最大的数据收集者
  • Apple 的 App Tracking Transparency（ATT）政策确实保护了用户隐私，但同时也削弱了竞争对手（Facebook/Meta）的广告业务，间接有利于 Apple 自己的广告平台

隐私保护和商业利益在 Apple 这里恰好是一致的，但这种一致性不是必然的。

6.4 Mozilla Firefox：理想主义的困境

6.4.1 非营利组织做浏览器

Mozilla 是一个独特的存在：它是唯一一个由非营利组织（Mozilla Foundation）控制的主流浏览器厂商。

Mozilla 的使命声明是："确保互联网是一个全球性的公共资源，对所有人开放和可访问。"

这听起来很崇高，但崇高的使命不能当饭吃。Mozilla 需要钱来雇佣工程师、维护 Firefox 和 Gecko 引擎。

6.4.2 Mozilla 的收入来源

Mozilla Corporation（Mozilla Foundation 的营利性子公司）2022 年的收入约为 5.93 亿美元。其中：

  • 约 85% 来自搜索引擎合作：主要是 Google 支付的默认搜索费用（约 5 亿美元/年）
  • 其余来自：广告收入（Firefox 新标签页的推荐内容）、Mozilla VPN 订阅、其他产品

6.4.3 致命的依赖

这里有一个深刻的讽刺：

Firefox 的存在意义是作为 Chrome 的替代品，但它的生存依赖于 Chrome 背后的公司（Google）的资助。

Google 为什么要资助自己的竞争对手？几个原因：

  1. 反垄断保护：如果 Firefox 死了，Chrome 就是事实上的垄断。有 Firefox 的存在，Google 可以说"市场上还有竞争"
  2. 搜索流量：Firefox 用户的搜索流量对 Google 仍然有价值
  3. 历史惯性：这个合作关系从 2004 年就开始了

但这个依赖关系是脆弱的。2025 年 DOJ 反垄断案的裁决禁止了排他性搜索协议，这可能影响 Google 和 Mozilla 未来的合作方式。Mozilla 的 CFO 在法庭上承认：如果失去 Google 的搜索收入，Mozilla 将面临"显著的裁员"和"下行螺旋"。

6.4.4 Mozilla 的多元化尝试

Mozilla 一直在尝试减少对 Google 的依赖：

  • Mozilla VPN：付费 VPN 服务
  • Firefox Relay：邮箱别名服务
  • Pocket：内容推荐平台（2017 年收购）
  • Mozilla.ai：AI 领域的探索
  • Fakespot：虚假评论检测工具（2023 年收购）

但这些业务的收入和 Google 的搜索分成相比微不足道。Mozilla 的财务困境是结构性的——在一个由广告驱动的互联网中，一个不做广告的组织很难自给自足。

6.5 Brave：重新发明广告

6.5.1 Brendan Eich 的第二次创业

Brave 的创始人是 Brendan Eich——对，就是 1995 年在 Netscape 用 10 天发明 JavaScript 的那个人，也是 Mozilla 的联合创始人。

2015 年，Eich 创办了 Brave，试图用一种全新的方式解决互联网广告的问题：

传统模式的问题：

广告商 → 广告平台（Google/Facebook）→ 网站 → 用户
         ↑                                    ↑
    拿走大部分收入                        被追踪、被打扰
    用户数据被收集                        没有任何回报

Brave 的模式：

广告商 → Brave → 用户
         ↑        ↑
    拿 30% 佣金   拿 70% 收入（BAT 代币）
    不收集用户数据  用户主动选择是否看广告

6.5.2 BAT（Basic Attention Token）

BAT 是 Brave 生态的核心——一种基于以太坊的加密代币：

  • 广告商用 BAT 购买广告位
  • 用户选择观看隐私友好的广告，获得 70% 的 BAT 奖励
  • 内容创作者可以接收用户的 BAT 打赏

关键区别：Brave 的广告匹配在本地完成（在你的设备上），不需要把你的数据发送到任何服务器。广告商知道"有人看了我的广告"，但不知道是谁看的。

6.5.3 Brave 的其他收入来源

除了 BAT 广告，Brave 还有：

  • Brave Search：自己的搜索引擎（有付费无广告版本）
  • Brave VPN：付费 VPN 服务
  • Brave Talk：视频会议服务
  • 搜索引擎合作：和其他搜索引擎的默认位置协议

6.5.4 Brave 的争议

Brave 不是没有争议：

  • 2020 年被发现在用户输入加密货币交易所 URL 时自动添加推荐链接（后来道歉并修复）
  • BAT 代币的实际价值波动很大，用户赚到的钱很少（每月几美元）
  • "屏蔽别人的广告，然后卖自己的广告"这个模式在道德上有争议

但从技术和隐私角度看，Brave 确实提供了目前最好的开箱即用隐私保护。

6.6 Microsoft Edge：云服务的入口

6.6.1 微软为什么还要做浏览器

微软的核心业务早已不是 Windows，而是：

  • Azure 云服务：年收入超过 900 亿美元
  • Microsoft 365：Office 套件的订阅服务
  • LinkedIn：职业社交网络
  • GitHub：开发者平台

Edge 在这个版图中的角色是：

  1. 推广 Bing 和 Copilot：Edge 默认搜索引擎是 Bing，集成了 AI 助手 Copilot
  2. 推广 Microsoft 365：Edge 和 Office Online 深度集成
  3. 企业市场：Edge 有企业管理功能，和 Azure AD 集成，是企业 IT 管理的一部分
  4. 数据收集：为 Bing 广告和 AI 训练提供数据

6.6.2 Edge 的"激进推广"

微软在推广 Edge 上的手段经常被用户批评：

  • Windows 11 中更改默认浏览器的步骤被故意设计得很复杂
  • 在 Windows 搜索中点击链接会强制用 Edge 打开
  • 定期弹窗建议你"试试 Edge"
  • 在 Bing 搜索 "Chrome" 时显示推荐 Edge 的广告

这些做法让人想起当年 IE 捆绑 Windows 的策略——只不过现在的用户有更多选择，微软的手段也没有当年那么有效。

6.7 浏览器经济学总结

6.7.1 收入对比

公司 浏览器 年收入（估算） 主要收入来源
Google (Alphabet) Chrome ~4000 亿美元（公司总收入） 广告（75-80%）
Apple Safari ~200 亿美元（搜索分成） Google 支付的默认搜索费
Microsoft Edge 难以单独计算 Bing 广告 + 企业服务
Mozilla Firefox ~6 亿美元 Google 搜索分成（85%）
Brave Brave ~1-2 亿美元（估算） BAT 广告 + 订阅服务

6.7.2 谁在为"免费"买单

Google Chrome:  你的数据和注意力 → 广告商付费
Apple Safari:   Google 付费（200 亿/年）→ 最终还是广告商付费
Firefox:        Google 付费（5 亿/年）→ 最终还是广告商付费
Brave:          广告商付费（但用户拿 70%）
Edge:           微软用其他业务的利润补贴

一个有趣的结论：几乎所有"免费"浏览器的最终资金来源都是广告行业。即使是 Apple 和 Mozilla 这样声称保护隐私的公司，它们的浏览器收入也间接来自 Google 的广告利润。

互联网的"免费"模式建立在广告之上，而广告建立在用户数据之上。这个结构性矛盾是所有隐私问题的根源。

6.7.3 有没有其他可能

有没有一种浏览器商业模式不依赖广告？

付费浏览器：理论上可行，但用户已经习惯了免费。Vivaldi 和一些小众浏览器尝试过付费模式，市场反应冷淡。

订阅制：Brave 的 VPN 和 Firefox 的 Relay 都是这个方向的尝试。但订阅收入很难覆盖浏览器开发的巨大成本。

公共资助：像 BBC 那样用公共资金维护一个"公共浏览器"？欧盟曾讨论过类似的想法，但从未落地。

开源社区：完全由志愿者维护？对于浏览器这种复杂度的软件来说不现实——Chromium 有 3500 万行代码，需要全职工程师团队。

目前看来，没有完美的答案。但至少我们可以做一个知情的选择——了解每个浏览器背后的商业动机，然后决定你愿意用什么来"付费"。

6.8 结语：选择你的浏览器

6.8.1 没有完美的选择

每个浏览器都有取舍：

  • Chrome：最好的兼容性和性能，但隐私最差
  • Firefox：最好的理念和独立性，但市场份额在萎缩
  • Brave：最好的开箱即用隐私，但商业模式有争议
  • Safari：Apple 生态内体验最好，但只限 Apple 设备
  • Edge：企业环境下最方便，但微软的推广方式令人反感

6.8.2 我的建议

作为一个了解了浏览器历史、技术和商业模式的人，你可以做出更明智的选择：

  1. 如果你最在意隐私：用 Brave 或配置好的 Firefox
  2. 如果你最在意兼容性：用 Chrome（但装上 uBlock Origin）
  3. 如果你在 Apple 生态：Safari 是合理的默认选择
  4. 如果你想支持 Web 多样性：用 Firefox（即使只是偶尔用）
  5. 如果你是开发者：主力用 Chrome DevTools，但用 Firefox 做兼容性测试

最重要的是：不要只用一个浏览器。多用几个浏览器，既是为了你自己的隐私（不同场景用不同浏览器），也是为了整个 Web 生态的健康。

6.8.3 浏览器的未来

浏览器已经从一个"看网页的工具"演变成了现代计算的基础设施。今天你在浏览器里可以：

  • 编辑文档（Google Docs）
  • 写代码（VS Code Web、GitHub Codespaces）
  • 剪辑视频（Clipchamp）
  • 玩 3D 游戏（WebGPU）
  • 运行 AI 模型（WebNN、WebGPU）
  • 进行视频会议（WebRTC）

浏览器正在变成一个"操作系统之上的操作系统"。Chrome OS 已经证明了这一点——一个只有浏览器的操作系统，足以满足大多数人的日常需求。

在 AI 时代，浏览器的角色可能会进一步演变。Edge 已经集成了 Copilot，Chrome 在实验 Gemini 集成，Opera 有内置的 AI 助手。浏览器可能从"你主动搜索信息"变成"AI 主动为你获取和整理信息"。

6.8.4 写给科大同学

如果你是计算机相关专业的学生，浏览器是一个绝佳的学习对象：

  • 想学网络协议？浏览器实现了 DNS、TCP、TLS、HTTP/2、HTTP/3、WebSocket...
  • 想学编译原理？JavaScript 引擎的 JIT 编译器是教科书级的案例
  • 想学操作系统？Chrome 的多进程架构、沙箱、IPC 机制都是 OS 概念的应用
  • 想学图形学？渲染引擎的布局算法、GPU 合成、WebGL/WebGPU 都是图形学的前沿
  • 想学安全？浏览器是攻防对抗最激烈的战场之一
  • 想学分布式系统？浏览器同步、Service Worker、Cache API 都涉及分布式概念

Chromium 的源码是完全开放的（chromium.googlesource.com），你可以阅读世界上最复杂的软件之一的实现细节。Firefox 的源码也是开放的（searchfox.org）。

如果你对浏览器开发感兴趣，可以从给 Firefox 或 Chromium 提交 bug fix 开始——这两个项目都有 "good first bug" 标签，专门为新贡献者准备。

但无论技术如何演变，本书讨论的核心问题不会消失：

  • 谁控制了入口，谁就有权力
  • 免费的代价是你的数据和注意力
  • 多样性和竞争是创新的前提
  • 隐私是一种需要主动维护的权利

三十年前，Tim Berners-Lee 设想的是一个开放、去中心化、人人平等的 Web。三十年后，Web 被少数几家公司控制，用户的数据被大规模收集和交易。

但历史也告诉我们：垄断不是永恒的。IE 曾经占据 95% 的市场，现在已经死了。Chrome 今天占据 67%，谁知道十年后会怎样？

保持好奇，保持警惕，做一个知情的用户。
