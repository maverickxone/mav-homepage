§ 引子

它不是聊天框里的 AI。它住进你的终端，读你的代码、改你的文件、跑你的命令， 并且会在关键时刻停下来问你一句：是否允许我继续？

这本小书想把它讲清楚——从它是什么，到它会怎么出错，到一些藏在源码里没人告诉你的东西。

§ 写给谁

所有初次和Claude Code打交道的人，你或多或少听过、用过 ChatGPT、写过 prompt，但 Claude Code 这个工具——它如何在终端里跑、为什么能改你的文件、什么时候会翻车——还是一团雾。这本书将带你完善每个细节，理解什么是真正的agent.

前三章覆盖新手指导，第四章讲心智模型，第五章讲缓存与计费机制，第六章讲彩蛋和冷知识，最后一节是速查表——所有命令、快捷键、配置项一页打开。

每章 25–35 分钟。开着终端边读边试，效果最好——写到 /plan 的时候打开 Claude Code 输入 /plan，看实际是什么样。读到这本书最后一页的时候，你会明显感觉自己彻底熟悉整个操作了。

致读者 / NOTE

你目前可能只认识 /status、/exit、/btw、/rename 这几个命令。读完这本书，你会从「能用它」变成「知道它在做什么」——后者比前者重要得多。

遇到不懂的地方，打开终端，敲 claude，问它。它自己就是关于自己最好的文档。读到第二章会发现，本指南里大量段落点击命令名能弹出详情——一边读一边查，比死记硬背快。
