常见错误与习题

常见错误与解决方案

形状不匹配错误

# 错误：矩阵乘法维度不匹配
A = torch.randn(2, 3)
B = torch.randn(5, 4)
C = A @ B  # RuntimeError: mat1 and mat2 shapes cannot be multiplied

# 解决：确保维度匹配
B = torch.randn(3, 4)
C = A @ B  # 正确：(2,3) @ (3,4) -> (2,4)

设备不匹配错误

# 错误：模型在GPU，数据在CPU
model = nn.Linear(10, 2).cuda()
data = torch.randn(2, 10)  # 默认在CPU
output = model(data)  # RuntimeError: Expected all tensors to be on the same device

# 解决：将数据移到GPU
data = data.cuda()
# 或
data = data.to('cuda')

梯度未清零

# 错误：梯度累积导致训练异常
for epoch in range(10):
    loss = net(x)
    loss.backward()
    optimizer.step()  # 忘记清零！

# 解决：每次迭代前清零
for epoch in range(10):
    optimizer.zero_grad()
    loss = net(x)
    loss.backward()
    optimizer.step()

类型不匹配

# 错误：类型不匹配
x = torch.randn(3, 4, dtype=torch.float32)
weight = torch.randn(4, 2, dtype=torch.float64)
output = x @ weight  # RuntimeError

# 解决：确保类型一致
weight = weight.float()  # 或 dtype=torch.float32

习题参考解答

解答 1：
输出：2 torch.Size([2, 3]) torch.int64
理由：a 是 2x3 矩阵，维度为 2；整数输入默认为 int64。   [ 返回习题 ]

解答 2：

  • arange 指定步长（不含末位），适合循环计数。
  • linspace 指定点数（含末位），适合采样。   [ 返回习题 ]

解答 3：
输出：tensor(999.)
原因：from_numpy 共享内存。修正：使用 torch.tensor(np_arr) 复制数据。   [ 返回习题 ]

解答 4：

  • A @ B 形状为 (3, 2)。
  • torch.mul(A, B) 形状为 (3, 4)。区别：矩阵乘法（聚合运算） vs 逐元素乘法（无聚合）。   [ 返回习题 ]

解答 5：

  1. t.reshape(8, 12) (OK)
  2. t.reshape(2, -1) (OK)
  3. t.reshape(8, 3, 5) (无法转换：元素总数不符)。   [ 返回习题 ]

解答 6：
导数：$6x_0 = 12$，$3x_1^2 = 27$。结果：tensor([12., 27.])。   [ 返回习题 ]

解答 7：
错误：缺少 optimizer.zero_grad()。PyTorch 梯度默认累积，不清零会导致训练爆炸。   [ 返回习题 ]

解答 8：
$4 \times 3$ (权重矩阵) + $3$ (偏置) = 15个参数。   [ 返回习题 ]
