热力学第二定律与熵

3.1 第一定律的不足

第一定律告诉你能量守恒——但它没有告诉你方向。

举个例子：一块冰放在热水里，冰融化、水变凉——能量从热水流向冰，总能量守恒。反过来呢？水自发冷却、冰自发变更冷——能量从冰流向水——这也不违反能量守恒。但这件事从来不会自发发生。

第一定律允许的过程中，只有一部分能够自发进行。需要一条新的定律来区分"能发生"和"不能发生"——这就是第二定律。

3.2 可逆过程与不可逆过程

不可逆过程

所谓不可逆过程：过程发生后，系统和外界不可能同时完全恢复原状。

典型例子：

  • 热量从高温物体自发流向低温物体
  • 气体向真空自由膨胀
  • 有摩擦的机械运动
  • 电流通过电阻产生焦耳热
  • 不同气体的自发混合

这些过程有一个共同特征：它们都有一个自发方向——热不会自发从冷处跑到热处，气体不会自发收缩到容器的一角。

可逆过程

可逆过程：过程发生后，系统和外界可以同时完全恢复原状，不留下任何痕迹。

可逆过程的两个条件：

  1. 过程是准静态的（系统时刻处于平衡态）
  2. 没有耗散（没有摩擦、电阻生热等不可逆因素）

可逆过程是一种理想极限。所有实际过程都是不可逆的（至少有微小的温度梯度、压强差或摩擦）。

为什么关心可逆过程

因为对于给定的初末态：

  • 可逆过程是效率最高的过程
  • 可逆热机是效率最大的热机（卡诺定理）
  • 可逆过程给出了热力学的理论上限

3.3 卡诺循环

设计思路

卡诺循环是热力学中最重要的理想循环。卡诺（1824）问了一个问题：热机的效率有没有上限？最高能到多少？

他设计了一种理想热机——只在两个恒温热源之间工作，且所有过程都可逆。这就是卡诺热机。

四个步骤

卡诺循环由四步组成（以理想气体为工质）：

① 等温膨胀（$T_1$，高温）：

  • 气体与高温热源接触，缓慢膨胀
  • 从高温热源吸热 $Q_1$
  • 温度不变，内能不变
  • $Q_1 = W_1 = nRT_1\ln(V_2/V_1)$

② 绝热膨胀（$T_1 \to T_2$）：

  • 断开热源，气体继续膨胀
  • 不吸热不放热
  • 温度从 $T_1$ 降到 $T_2$
  • $T_1 V_2^{\gamma-1} = T_2 V_3^{\gamma-1}$

③ 等温压缩（$T_2$，低温）：

  • 气体与低温热源接触，缓慢压缩
  • 向低温热源放热 $Q_2$
  • $Q_2 = nRT_2\ln(V_3/V_4)$（放出的热量）

④ 绝热压缩（$T_2 \to T_1$）：

  • 断开热源，继续压缩
  • 温度从 $T_2$ 升回 $T_1$
  • 回到初态

卡诺循环效率

净功 $W = Q_1 - Q_2$（回到初态，内能变化为零）。

效率：

$\eta_C = \frac{W}{Q_1} = 1 - \frac{Q_2}{Q_1}$

利用绝热过程的关系 $T_1V_2^{\gamma-1} = T_2V_3^{\gamma-1}$ 和 $T_1V_1^{\gamma-1} = T_2V_4^{\gamma-1}$，可以证明 $V_2/V_1 = V_3/V_4$，因此：

$\frac{Q_2}{Q_1} = \frac{nRT_2\ln(V_3/V_4)}{nRT_1\ln(V_2/V_1)} = \frac{T_2}{T_1}$

最终：

$\boxed{\eta_C = 1 - \frac{T_2}{T_1}}$

关键结论

  • 效率只取决于两个热源的温度，和工质（什么气体）无关
  • $T_1$ 越高或 $T_2$ 越低，效率越高
  • $\eta < 1$（除非 $T_2 = 0$ K，但绝对零度不可达）
  • 不可能制造效率为 100% 的热机

卡诺定理

卡诺定理（两部分）：

  1. 在相同的高温热源 $T_1$ 和低温热源 $T_2$ 之间工作的所有热机中，可逆热机的效率最高。
  2. 所有在 $T_1$ 和 $T_2$ 之间工作的可逆热机效率相同，等于 $1 - T_2/T_1$。

即：对任意热机：

$\eta \leq \eta_C = 1 - \frac{T_2}{T_1}$

等号在可逆（卡诺）热机时取到。

3.4 热力学第二定律

两种等价表述

克劳修斯表述：热量不能自发地从低温物体传向高温物体，而不引起其他变化。

开尔文-普朗克表述：不可能从单一热源吸热并将其完全转化为功，而不引起其他变化。

"不引起其他变化"是关键——冰箱确实把热量从冷处搬到热处，但它消耗了电能（引起了其他变化）。

两种表述的等价性

可以证明：如果克劳修斯表述被违反，那么开尔文表述也被违反；反之亦然。

证明思路（克劳修斯被违反→开尔文被违反）：

假设存在一个"完美导热器"，能自发把热量 $Q$ 从冷源（$T_2$）搬到热源（$T_1$），不消耗功。那么让一个正常热机从 $T_1$ 吸热 $Q_1$、做功 $W$、向 $T_2$ 放热 $Q_2$。让完美导热器把 $Q_2$ 从 $T_2$ 搬回 $T_1$。总效果：从 $T_1$ 净吸热 $Q_1 - Q_2 = W$，全部变成功，冷源不变——违反了开尔文表述。

第二定律的本质

第二定律本质上是关于过程方向性的定律。它说的是：

  • 自然过程有方向
  • 摩擦生热不能逆转（生的热不能自发变回有序运动）
  • 热机效率有上限
  • 存在一个态函数（熵）描述这种方向性

3.5 克劳修斯不等式

推导思路

对任意循环过程（可逆或不可逆），考虑系统和多个热源交换热量。设系统在温度 $T_i$ 的热源处吸热 $\text{đ}Q_i$。

由卡诺定理可以推导出（详细证明较长，这里给出关键结论）：

$\boxed{\oint \frac{\text{đ}Q}{T} \leq 0}$

等号对可逆循环成立，不等号对不可逆循环成立。

这里 $T$ 是热源的温度（如果过程可逆，系统温度等于热源温度）。

含义

克劳修斯不等式是第二定律的数学表达。它告诉你：不可逆循环中 $\oint \frac{\text{đ}Q}{T} < 0$。这意味着 $\frac{\text{đ}Q}{T}$ 沿不可逆路径的积分不为零——它不是一个态函数的全微分。

但如果限定可逆过程，$\oint \frac{\text{đ}Q_{rev}}{T} = 0$——这意味着 $\frac{\text{đ}Q_{rev}}{T}$ 是某个态函数的全微分。这个态函数就是熵。

3.6 熵的定义

从克劳修斯不等式到熵

对可逆循环：

$\oint \frac{\text{đ}Q_{rev}}{T} = 0$

这意味着 $\int_A^B \frac{\text{đ}Q_{rev}}{T}$ 的值只取决于初态 A 和末态 B，和路径无关（否则对不同路径积分值不同，绕一圈就不为零）。

因此可以定义一个新的状态量——熵 $S$：

$\boxed{dS = \frac{\text{đ}Q_{rev}}{T}}$

或者有限变化：

$\Delta S = S_B - S_A = \int_A^B \frac{\text{đ}Q_{rev}}{T}$

关键理解

  1. 熵是状态量——和内能一样，只取决于系统当前状态
  2. 计算时必须用可逆路径——定义中的 $\text{đ}Q_{rev}$ 强调的是可逆过程的热量
  3. 但 $\Delta S$ 和实际过程无关——不管实际过程多么不可逆，$\Delta S$ 只取决于初末态。只是你需要找一条可逆路径来计算它

这是初学者最容易困惑的地方：实际过程可能是不可逆的，但你用一条虚拟的可逆路径来算 $\Delta S$，算出来的就是真实的熵变。

3.7 熵变的计算

计算策略

不管实际过程是什么，计算 $\Delta S$ 的步骤都是：

  1. 确定初态 $(T_1, V_1)$（或 $(T_1, p_1)$）和末态 $(T_2, V_2)$
  2. 设计一条连接初末态的可逆路径（可以和实际路径完全不同）
  3. 沿可逆路径计算 $\int \frac{\text{đ}Q_{rev}}{T}$

理想气体的熵变公式

对 $n$ mol 理想气体，从 $(T_1, V_1)$ 到 $(T_2, V_2)$：

设计可逆路径：先等容加热从 $T_1$ 到 $T_2$（$V$ 不变），再等温膨胀从 $V_1$ 到 $V_2$（$T$ 不变）。

等容步：$\text{đ}Q_{rev} = nC_{V,m},dT$

$\Delta S_1 = \int_{T_1}^{T_2} \frac{nC_{V,m},dT}{T} = nC_{V,m}\ln\frac{T_2}{T_1}$

等温步：$\text{đ}Q_{rev} = p,dV = \frac{nRT}{V},dV$

$\Delta S_2 = \int_{V_1}^{V_2} \frac{nR}{V},dV = nR\ln\frac{V_2}{V_1}$

总熵变：

$\boxed{\Delta S = nC_{V,m}\ln\frac{T_2}{T_1} + nR\ln\frac{V_2}{V_1}}$

等价地，用 $(T, p)$ 表示（利用 $V = nRT/p$ 代入）：

$\Delta S = nC_{p,m}\ln\frac{T_2}{T_1} - nR\ln\frac{p_2}{p_1}$

特殊过程的熵变

等温过程（$T_1 = T_2$）：

$\Delta S = nR\ln\frac{V_2}{V_1} = nR\ln\frac{p_1}{p_2}$

等容过程（$V_1 = V_2$）：

$\Delta S = nC_{V,m}\ln\frac{T_2}{T_1}$

等压过程（$p_1 = p_2$）：

$\Delta S = nC_{p,m}\ln\frac{T_2}{T_1}$

绝热可逆过程：$\text{đ}Q_{rev} = 0$，所以 $\Delta S = 0$。可逆绝热过程是等熵过程。

例题思路：自由膨胀的熵变

理想气体从 $V_1$ 自由膨胀到 $V_2$（真空膨胀）。

实际过程：不可逆，$Q = 0$，$W = 0$，$\Delta U = 0$→$\Delta T = 0$（理想气体）。

但你不能直接用 $\Delta S = Q/T = 0$ 来算——因为过程不可逆，$\text{đ}Q/T$ 的积分不等于 $\Delta S$。

正确方法：找一条可逆路径连接同样的初末态（$T$ 不变，$V_1 \to V_2$）→等温可逆膨胀。

$\Delta S = nR\ln\frac{V_2}{V_1} > 0$

熵增加了！虽然系统没有吸热，但不可逆过程导致熵增。

3.8 熵增原理

表述

对于孤立系统：

$\Delta S_{total} \geq 0$

等号对可逆过程成立，不等号对不可逆过程成立。

孤立系统的熵永不减少。 这就是熵增原理——第二定律的又一种表述。

推导

对孤立系统，$Q = 0$。由克劳修斯不等式（对从 A 到 B 的过程再加上从 B 回到 A 的可逆过程构成循环）：

$\int_A^B \frac{\text{đ}Q}{T} + \int_B^A \frac{\text{đ}Q_{rev}}{T} \leq 0$

第一项：实际过程中 $\text{đ}Q = 0$（孤立系统），所以为零。 第二项：$= -(S_B - S_A) = -\Delta S$。

$0 - \Delta S \leq 0 \quad \Rightarrow \quad \Delta S \geq 0$

非孤立系统怎么办

如果系统不是孤立的（和外界有热交换），需要考虑系统 + 外界的总熵变：

$\Delta S_{系统} + \Delta S_{外界} \geq 0$

系统的熵可以减少（比如冰箱里的空气变冷，熵降低），只要外界的熵增加得更多（冰箱散热到外面）。

熵的统计意义（预览）

玻尔兹曼给出了熵的微观解释：

$S = k\ln\Omega$

其中 $\Omega$ 是系统微观状态的数目。熵大 = 微观状态多 = 更"混乱"。

熵增 = 系统从微观状态少的状态（有序）自发演化到微观状态多的状态（无序）。这不是"不可能"逆转，而是逆转的概率低到可以忽略（$10^{-10^{23}}$ 量级）。

3.9 熵变计算的更多例子

两物体接触达到热平衡

质量为 $m_1$ 的物体（初温 $T_1$，比热 $c_1$）与质量为 $m_2$ 的物体（初温 $T_2 < T_1$，比热 $c_2$）接触。假设两者组成孤立系统。

末态温度由能量守恒确定：

$m_1 c_1(T_1 - T_f) = m_2 c_2(T_f - T_2)$

$T_f = \frac{m_1 c_1 T_1 + m_2 c_2 T_2}{m_1 c_1 + m_2 c_2}$

各物体的熵变（设计可逆的缓慢加热/冷却路径）：

$\Delta S_1 = m_1 c_1 \ln\frac{T_f}{T_1} < 0 \quad \text{（降温，熵减）}$

$\Delta S_2 = m_2 c_2 \ln\frac{T_f}{T_2} > 0 \quad \text{（升温，熵增）}$

总熵变：

$\Delta S_{total} = m_1 c_1 \ln\frac{T_f}{T_1} + m_2 c_2 \ln\frac{T_f}{T_2}$

可以证明 $\Delta S_{total} > 0$（利用 $\ln x \geq 1 - 1/x$ 等不等式，或者直接用 Jensen 不等式）。这验证了熵增原理：不可逆的热传递过程使总熵增加。

特殊情况：如果两物体材料相同、质量相同（$m_1c_1 = m_2c_2$），则 $T_f = (T_1+T_2)/2$，总熵变：

$\Delta S_{total} = mc\ln\frac{(T_1+T_2)^2}{4T_1T_2} > 0$

（因为算术平均 $\geq$ 几何平均：$(T_1+T_2)/2 \geq \sqrt{T_1T_2}$）

理想气体的不可逆等压膨胀

$n$ mol 理想气体在恒压 $p$ 下从 $T_1$ 加热到 $T_2$。这是一个可逆过程（缓慢加热），可以直接算：

$\Delta S_{系统} = nC_{p,m}\ln\frac{T_2}{T_1}$

如果热源温度恒为 $T_2$（有限温差传热，不可逆），则热源放出热量 $Q = nC_{p,m}(T_2 - T_1)$：

$\Delta S_{热源} = -\frac{Q}{T_2} = -\frac{nC_{p,m}(T_2-T_1)}{T_2}$

总熵变：

$\Delta S_{total} = nC_{p,m}\left(\ln\frac{T_2}{T_1} - \frac{T_2-T_1}{T_2}\right) = nC_{p,m}\left(\ln\frac{T_2}{T_1} - 1 + \frac{T_1}{T_2}\right) > 0$

（利用 $\ln x \leq x - 1$ 可证最后一个不等号）

3.10 T-S 图

引入

除了 p-V 图，T-S 图（横轴熵 $S$，纵轴温度 $T$）也是热力学中很有用的工具。

热量的几何意义

由 $\text{đ}Q_{rev} = T,dS$，可逆过程中吸收的热量：

$Q = \int T,dS$

这是 T-S 图上过程曲线下方的面积——类似于 p-V 图上功等于曲线下方面积。

图 横轴 纵轴 曲线下面积
p-V 图 $V$ $p$ 功 $W$
T-S 图 $S$ $T$ 热量 $Q$

卡诺循环在 T-S 图上

在 T-S 图上，卡诺循环变成一个简单的矩形：

  • 上边：等温吸热（$T = T_1$，$S$ 增大）
  • 下边：等温放热（$T = T_2$，$S$ 减小）
  • 左边：绝热压缩（$S$ = const，$T$ 上升）
  • 右边：绝热膨胀（$S$ = const，$T$ 下降）

矩形面积 = $(T_1 - T_2)(S_2 - S_1) = Q_1 - Q_2 = W$。

效率 = 面积 / 上边下面积 = $(T_1 - T_2)/T_1 = 1 - T_2/T_1$。在 T-S 图上，卡诺效率的含义一目了然。

3.11 自由能简介

动机

熵增原理用于孤立系统很方便——但实际中大部分系统不是孤立的（比如等温等压条件下的化学反应）。能不能构造一个判据，不需要算外界的熵变？

答案：引入自由能，把"系统 + 外界"的熵变判据转化为只涉及系统的判据。

亥姆霍兹自由能 $F$

定义：

$F = U - TS$

对于等温等容过程（$T$ 不变，$V$ 不变，不做体积功）：

$\Delta F = \Delta U - T\Delta S$

可以证明：等温等容条件下，$\Delta F \leq 0$（自发过程使 $F$ 减小）。平衡时 $F$ 取极小值。

吉布斯自由能 $G$

定义：

$G = U - TS + pV = H - TS$

其中 $H = U + pV$ 是焓（enthalpy）。

对于等温等压过程：

$\Delta G \leq 0 \quad \text{（自发过程）}$

平衡时 $G$ 取极小值。

这在化学中极其重要——化学反应通常在等温等压（大气压、恒温水浴）条件下进行，$\Delta G < 0$ 就是判断反应能否自发进行的标准。

本课程中的位置

自由能的详细应用超出了本课六周的范围，但理解它的动机和基本定义对于完整理解热力学框架是必要的。核心要记住：

  • 孤立系统：$\Delta S \geq 0$（熵增判据）
  • 等温等容：$\Delta F \leq 0$
  • 等温等压：$\Delta G \leq 0$

3.12 概念辨析

Q：熵是"混乱度"吗？

这是一种直觉上有用但不严格的说法。更精确地说，熵度量的是系统微观状态的数目（$S = k\ln\Omega$）。"混乱"只是对"微观状态数多"的一种粗略类比。

在某些情况下这个类比会误导——比如液态水结晶成冰，看起来更"有序"（熵减小），但这不意味着违反第二定律：水放热给环境，环境熵增加得更多，总熵仍然增加。

Q：可逆绝热 = 等熵。那不可逆绝热呢？

不可逆绝热过程中 $Q = 0$，但 $\Delta S > 0$——熵增加了。

这看起来矛盾：$dS = \text{đ}Q_{rev}/T$，如果 $Q = 0$，$S$ 怎么能变？

关键：$dS = \text{đ}Q_{rev}/T$ 只在可逆过程中等号成立。不可逆过程中 $dS > \text{đ}Q/T$。即使 $\text{đ}Q = 0$，也有 $dS > 0$——不可逆性本身"产生"了熵。

Q：效率为什么不能到 100%？

由卡诺效率 $\eta = 1 - T_2/T_1$，要让 $\eta = 1$，需要 $T_2 = 0$ K。但热力学第三定律告诉我们绝对零度不可达。

物理上：热机工作必须向低温热源放热——你需要一个"垃圾桶"来倾倒不可用的热量。没有低温热源（或低温热源温度为零），热机无法运转。

Q：空调制冷违反第二定律吗？

不违反。克劳修斯表述说的是热量不能自发地、不引起其他变化地从冷源流向热源。空调消耗了电能（功），这就是"其他变化"。第二定律不禁止制冷，它只是要求你付出代价。

3.13 本章公式总结

卡诺效率

$\eta_C = 1 - \frac{T_2}{T_1} \tag{3.1}$

克劳修斯不等式

$\oint \frac{\text{đ}Q}{T} \leq 0 \tag{3.2}$

熵的定义

$dS = \frac{\text{đ}Q_{rev}}{T} \tag{3.3}$

理想气体熵变

$\Delta S = nC_{V,m}\ln\frac{T_2}{T_1} + nR\ln\frac{V_2}{V_1} \tag{3.4}$

$\Delta S = nC_{p,m}\ln\frac{T_2}{T_1} - nR\ln\frac{p_2}{p_1} \tag{3.5}$

熵增原理

$\Delta S_{孤立系统} \geq 0 \tag{3.6}$

自由能

$F = U - TS, \quad G = H - TS = U + pV - TS \tag{3.7}$
