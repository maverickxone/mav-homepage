第五章：实战选购——从需求到配置

5.1 轻薄本 vs 游戏本 vs 台式机：选形态就是选生活方式

🎬 开场：一个大一新生的纠结

开学前一个月，你的购物车里躺着三台电脑：

  • 一台 1.2kg 的轻薄本，续航 15 小时，带去图书馆毫无压力，售价 5999 元；
  • 一台 2.5kg 的游戏本，RTX 4060 显卡，能在宿舍畅玩《黑神话：悟空》，售价 7499 元；
  • 一套 台式机配置单，同价位性能最强，但搬不进图书馆，售价 5500 元（不含显示器）。

你妈问你："到底买哪个？"你说："我也不知道。"

这不是一个技术问题，而是一个生活方式问题。让我们把三种形态的电脑放在解剖台上，看看它们的设计哲学到底有什么不同。

📐 核心概念：三种形态的本质差异

理解一个根本矛盾：性能 vs 便携 vs 散热

在第二章我们讲过，CPU 和 GPU 工作时会产生大量热量。在第四章我们提到，散热系统的设计直接决定了芯片能释放多少性能。现在，这个知识要派上用场了。

电脑设计中有一个经典的"不可能三角"：

        性能
       /    \
      /      \
   便携 ———— 散热

你不可能同时拥有极致的性能、极致的便携和极致的散热。每一种电脑形态，都是在这个三角形中选择了不同的平衡点。

轻薄本：便携优先，性能够用

设计哲学：把电脑做成"随身工具"，像课本一样塞进书包，全天候使用不需要找插座。

核心取舍：

维度 轻薄本的选择
重量 1.0–1.5kg（含电源适配器约 1.5–2.0kg）
厚度 12–16mm
CPU 低功耗版（TDP 通常 15–28W），如 Intel Core Ultra 5 125U、AMD Ryzen 7 8840U
GPU 核显（集成显卡）或入门级独显（如 MX 570A）
续航 8–15 小时（日常使用）
风扇噪音 日常使用几乎无声
典型价格 4000–8000 元（2025 年主流价位）

谁适合轻薄本？

  • 经常在教室、图书馆、咖啡厅之间迁移的同学
  • 主要用途是写文档、做 PPT、浏览网页、看网课、写代码（非大型项目编译）
  • 不玩大型 3A 游戏，或者可以接受"游戏用别的设备"
  • 看重续航，讨厌随身带大号充电器

一个直观的类比：轻薄本就像一辆城市代步车——油耗低、停车方便、堵车不慌，但你别指望它去越野或者拉货。

💡 关于"全能本"：近两年市场上出现了一个新品类叫"全能本"或"高性能轻薄本"，重量在 1.5–1.8kg，配备 RTX 4050/4060 级别独显，试图在轻薄和性能之间取一个折中。代表产品如联想小新 Pro 16、华硕无畏 Pro 系列等。它们确实是不错的选择，但请记住：物理规律不可违背，折中意味着两边都不会做到极致。

游戏本：性能优先，牺牲便携

设计哲学：在笔记本形态里塞入尽可能强的性能。你可以带着它移动，但它更像一台"可以搬走的台式机"。

核心取舍：

维度 游戏本的选择
重量 2.0–3.0kg（含电源适配器可达 3.5–4.5kg）
厚度 20–30mm
CPU 高性能版（TDP 通常 45–65W），如 Intel i7-14700HX、AMD Ryzen 9 8945HX
GPU 高性能独显，如 RTX 4060/4070/4080 Laptop
续航 3–6 小时（日常使用），游戏时 1–2 小时
风扇噪音 高负载时明显（可达 45–55 分贝，相当于正常对话音量）
典型价格 6000–15000 元（2025 年主流价位）

谁适合游戏本？

  • 爱玩 3A 大作或者竞技游戏（《CS2》《英雄联盟》倒是轻薄本也能跑）
  • 专业需要 GPU 算力：深度学习训练、3D 建模与渲染、视频剪辑
  • 能接受"主要在寝室和实验室用"，不介意背着重书包
  • 预算有限，不想同时买笔记本和台式机

一个直观的类比：游戏本就像一辆 SUV——动力够猛、空间够大，但油耗高、停车费劲，进城不如小车灵活。

⚠️ 游戏本的"Laptop 版"显卡陷阱：同样叫 RTX 4060，笔记本版（Laptop）和桌面版（Desktop）的性能差距可达 20–40%。原因在第二章讲过——功耗限制导致 GPU 不能以满血功率运行。所以看到游戏本标称的显卡型号，不要直接和台式机画等号。

台式机：性能拉满，放弃便携

设计哲学：没有体积限制，没有电池焦虑，所有预算都花在性能上。

核心取舍：

维度 台式机的选择
体积 中塔机箱约 45×20×45 cm（需要固定位置放置）
CPU 桌面版满血芯片（TDP 65–125W+），如 AMD Ryzen 5 9600X、Intel i5-14600KF
GPU 桌面版满血显卡，如 RTX 4060/4070 Desktop
散热空间 充足（支持大型塔式风冷或 240/360mm 水冷）
扩展性 高——可随时升级内存、显卡、硬盘
显示器 需单独购买（但可以选 27 寸大屏，体验远超笔记本）
电源 需要持续插电使用
典型价格 主机 4000–10000 元 + 显示器 800–3000 元（2025 年参考）

谁适合台式机？

  • 在宿舍/家里有固定工位，不需要经常带电脑出门
  • 追求极致性价比：同等预算，台式机性能通常比笔记本高 30–50%
  • 有升级需求：大二买的显卡不够用了，大三换一块就行
  • 重度游戏玩家、深度学习研究者、视频创作者

一个直观的类比：台式机就像一台 家用健身房器材——效果最好、可以不断加配件，但你得有地方放，而且搬家的时候很头疼。

同样的钱，台式机在性能层面几乎全方位碾压；游戏本在"可移动"和"高性能"之间取得平衡；轻薄本则用极致便携换取了最舒适的日常体验。

❌ 常见误区

❌ "游戏本可以当轻薄本用，功能更全" → ✅ 游戏本确实"能做"轻薄本的活儿，但每天背着 3kg 的电脑 + 1kg 的电源走来走去，加上 3 小时的续航和嗡嗡作响的风扇，你的体验会非常糟糕。形态选择的核心不是"能不能"，而是"爽不爽"。

❌ "台式机已经过时了，现在都用笔记本" → ✅ 台式机在性价比、扩展性和大屏体验上依然无可替代。对于有固定工位的同学，台式机 + 一台便宜的平板/轻薄本做笔记，往往是比一台高价游戏本更好的组合。

❌ "买最贵的就是最好的" → ✅ 如果你不玩游戏、不做视频剪辑，一台 15000 元的游戏本对你来说就是在为你根本用不到的 GPU 性能买单。需求不匹配的高配置就是浪费。

5.2 Windows PC vs Mac：不只是操作系统的战争

🎬 开场：宿舍里的"信仰之争"

大一入学第一周，宿舍四个人的桌上摆着四台电脑。两台 Windows 笔记本，一台 MacBook Air，还有一台 MacBook Pro。

用 Windows 的室友问："Mac 那么贵，花一万多就买了个 8GB 内存的，不亏吗？"

用 Mac 的室友反击："你那个 Windows 一天蓝屏两三次，还得装杀毒软件，不累吗？"

两边都说得有道理，也都有偏见。Windows 和 Mac 之间的选择，从来不是简单的"谁更好"——它涉及操作系统、硬件架构、软件生态和使用习惯。让我们把情绪放一边，从技术角度拆解这场"信仰之争"。

📐 核心概念：两条完全不同的技术路线

本质差异：开放平台 vs 封闭生态

在第二章我们讲过 x86 和 ARM 两种指令集架构，在第四章我们聊了苹果 M 系列 SoC 的革命性设计。现在这些知识要综合运用了。

Windows PC 和 Mac 的差异，远不止"装了不同的操作系统"那么简单。它们代表了两种完全不同的产品哲学：

维度 Windows PC Mac
硬件 数百个品牌、数千款配置，开放硬件标准 苹果独家设计和制造，型号有限
芯片架构 主要用 x86 架构（Intel/AMD） Apple Silicon（ARM 架构，M1/M2/M3/M4/M5 系列）
操作系统 Windows（微软开发，运行在各品牌硬件上） macOS（苹果开发，只运行在苹果硬件上）
软硬件关系 软硬件分离——操作系统和硬件来自不同公司 软硬件一体——苹果同时设计芯片、硬件和系统

这个区别可以用一个类比来理解：

Windows PC 就像安卓手机的生态——不同厂商用不同的硬件，跑同一个操作系统。选择多、价格跨度大，但体验参差不齐。

Mac 就像 iPhone——苹果自己设计一切，产品线简单，但每一款都经过深度优化。选择少，但"开箱即用"的体验通常更好。

Apple Silicon 到底强在哪？

在第四章我们已经介绍过 SoC（片上系统）的概念。苹果 M 系列芯片可能是目前消费级 SoC 最成功的案例。让我们具体聊聊它的优势和局限：

优势：

  1. 能效比惊人：M4 芯片（2024 年发布）的 CPU 在 10W 功耗下就能达到 Intel i7-14700H 在 45W 下的单线程性能。这意味着 MacBook Air 完全无风扇设计，依然能跑出中端 Windows 笔记本的性能。

  2. 统一内存架构（Unified Memory）：回忆第一章讲的存储金字塔——传统 PC 中，CPU 和 GPU 各有各的内存，数据要来回搬运。M 系列芯片让 CPU、GPU、NPU 共享同一块内存池，数据零拷贝。这就好比大厨和助手共用一张工作台，不需要把食材从一张桌子搬到另一张桌子。

  3. 电池续航：MacBook Air M4 可以连续视频播放 18 小时。同价位 Windows 轻薄本通常在 8–12 小时。ARM 架构天生比 x86 省电（原因在第二章讲过）。

  4. macOS 的深度优化：因为苹果同时控制硬件和软件，macOS 可以针对 M 芯片做极致优化。你打开 Safari、Final Cut Pro 等苹果自家应用时，能明显感受到丝滑流畅。

局限：

  1. 内存不可升级：MacBook 的内存焊死在芯片上（和 SoC 封装在一起）。你买 8GB 就是 8GB，买 16GB 就是 16GB，以后不能加。这一点在第一章讲内存时提到过——焊接内存牺牲了升级自由度。

  2. 游戏生态薄弱：大多数 PC 游戏是为 x86 + DirectX（Windows 图形 API）开发的。虽然苹果在积极推进 Metal API 和 Game Porting Toolkit，但目前 Mac 上能玩的 3A 大作远少于 Windows。

  3. 专业软件兼容性：部分工程类软件（如某些 EDA 工具、MATLAB 的特定工具箱、一些教学实验平台）只有 Windows 版。虽然可以通过虚拟机（Parallels Desktop）运行 Windows，但这意味着额外的成本和性能损失。

  4. 维修成本高：苹果产品一体化设计意味着一旦某个部件出问题，维修费可能非常夸张。换一块 MacBook Pro 的主板可能需要 4000–6000 元，而 Windows 笔记本换一块内存条可能只需要 200 元。

你会发现，Mac 的"账面参数"看起来不如同价位的 Windows 机器——内存更小、存储更少、没有独立显卡。但这里有一个关键点：Apple Silicon 的 8GB/16GB 统一内存和 Windows PC 的 8GB/16GB 内存并不是同一回事。

统一内存省去了数据在 CPU 内存和 GPU 显存之间的复制，效率更高。所以 Mac 上 16GB 的"体感"接近 Windows PC 上 24–32GB 的体验（在图形和视频处理场景下尤为明显）。但这不意味着你可以无视内存容量——如果你要同时开几十个 Chrome 标签页 + IDE + Slack + Zoom，16GB 也不够，Windows 和 Mac 都一样。

🎓 科大同学的特殊考量

作为中科大学生，你在选择时需要特别注意几个点：

  1. 课程软件兼容性：某些实验课可能指定使用 Windows 平台的软件（比如 Quartus、某些硬件仿真工具）。建议入学前向学长或老师确认。如果确实需要 Windows，Mac 可以通过 Parallels Desktop 虚拟机运行 Windows，但这是额外的成本（软件费约 500 元/年）并且性能会打折。

  2. 编程环境：如果你的方向是 Web 开发、iOS 开发或 AI 研究，macOS 基于 Unix 的终端环境会非常舒适——brew install 一行命令就能配好大部分开发工具。但如果是 .NET 开发或者需要大量使用 Visual Studio（不是 VS Code），Windows 是更自然的选择。

  3. 如果你需要 GPU 训练模型：MacBook 的 GPU 在深度学习方面的生态支持不如 NVIDIA（CUDA 不支持 Metal）。虽然 PyTorch 已支持 Apple GPU 加速（MPS 后端），但大部分教程和生产环境仍以 NVIDIA GPU + CUDA 为主。这种情况下，Windows 游戏本或台式机是更务实的选择，或者使用学校/云端的 GPU 资源。

  4. 生态锁定效应：如果你已经有 iPhone、iPad 和 AirPods，MacBook 和这些设备之间的协作是 Windows 无法复制的——AirDrop 传文件、Handoff 接力编辑、iCloud 同步笔记、用 iPad 做 Mac 的扩展屏幕（Sidecar）。这些功能不是必须的，但用过之后会很难回到"手动传文件"的时代。

❌ 常见误区

❌ "Mac 的 8GB 内存完全够用，等于 Windows 的 16GB" → ✅ 这个说法有一定道理但过于夸张。苹果统一内存确实效率更高，但内存不足就是内存不足。2025 年购买 Mac，强烈建议至少 16GB 起步。幸运的是，苹果从 M4 起已将入门款内存提升到 16GB。

❌ "Mac 不能装 Windows 所以什么都用不了" → ✅ Apple Silicon 的 Mac 可以通过 Parallels Desktop 运行 ARM 版 Windows 11，绝大多数日常软件（包括 Office、微信等）都能正常运行。只是部分对 x86 强依赖的老旧软件可能有兼容问题。

❌ "Windows 总是蓝屏、卡顿、不稳定" → ✅ Windows 11 的稳定性已经非常好了。大多数"不稳定"是二手/旧电脑年久失修或驱动不兼容导致的，而非系统本身的问题。一台硬件正常的新 Windows 笔记本，体验完全可以做到流畅稳定。

📐 核心概念：逐项解读参数表

1. 处理器（CPU）

示例：Intel Core i7-14700HX

这个型号名的每一段都有含义：

部分 含义
Intel Core 品牌和系列（Intel 的消费级产品线）
i7 定位等级：i3（入门）< i5（主流）< i7（高性能）< i9（旗舰）
14 第 14 代架构（代数越新通常越好，但不是线性提升）
700 同代同级中的具体型号编号
H 后缀标识功耗/定位

后缀是最容易被忽略但最重要的细节：

后缀 含义 TDP（功耗） 适合形态
U Ultra Low Power，超低功耗 15–28W 轻薄本
P Performance，性能优化低功耗 28W 轻薄本/全能本
H High Performance，高性能 45W 游戏本/全能本
HX Extreme High Performance，极致性能 55W+ 高端游戏本/移动工作站
K 不锁频（可超频） 65–125W 台式机
F 无核显 视搭配而定 台式机（必须配独显）
KF 不锁频 + 无核显 65–125W 台式机（高性价比之选）

AMD 的命名也有类似规律：

示例：AMD Ryzen 7 8845HS

部分 含义
Ryzen 7 定位等级（Ryzen 3/5/7/9，类似 Intel 的 i3/5/7/9）
8 代数标识
845 具体型号
HS 后缀：H = 高性能，S = 特调版本（同样看后缀区分功耗）

💡 实用建议：对于大多数大学生，i5/Ryzen 5 就够用了。i7/Ryzen 7 适合需要多任务处理或频繁编译大型项目的同学。i9/Ryzen 9 对学生来说通常是过剩的——除非你在做科研级的计算任务。

2. 显卡（GPU）

示例：NVIDIA GeForce RTX 4060 Laptop GPU 8GB GDDR6

拆解：

部分 含义
NVIDIA GeForce 品牌和消费级系列（专业卡是 Quadro/RTX A 系列）
RTX 支持光线追踪（Ray Tracing）和 AI 加速（Tensor Core）
40 第 40 代架构（代数越新越好）
60 定位：50（入门）< 60（主流）< 70（高性能）< 80（旗舰）< 90（顶级）
Laptop GPU 笔记本版本（功耗和性能低于桌面版）
8GB GDDR6 显存容量和类型

显卡关键参数补充：

  • 功耗（TGP，Total Graphics Power）：同一型号的 Laptop GPU，不同笔记本可能给它分配不同的功耗。比如 RTX 4060 Laptop 的功耗范围是 35W–115W，功耗越高性能越强。这就是为什么"同型号不同本"性能差距很大。
  • 显存：对于游戏和 AI 推理，8GB 显存在 2025 年是够用的基准线。如果要训练大模型或处理 4K 视频，建议 12GB+。

AMD 显卡：AMD 的显卡叫 Radeon RX 系列（如 RX 7600）。在中端价位，AMD 显卡性价比不错，但 NVIDIA 在 AI/深度学习领域的 CUDA 生态仍然是绝对领先。

💡 "核显够用吗？"：现代核显（如 Intel Arc 核显、AMD Radeon 780M）已经可以流畅运行《英雄联盟》《CS2》等热门网游，以及处理日常办公、网页浏览、视频播放。只有在你需要跑 3A 大作、做 3D 渲染或深度学习时，才必须上独显。

3. 内存（RAM）

示例：16GB DDR5 5600MHz

部分 含义
16GB 内存容量——同时能处理多少数据（上菜桌面积）
DDR5 内存代数——DDR4 → DDR5 是世代升级，DDR5 速度更快、功耗更低
5600MHz 频率——数据传输速度（频率越高，理论带宽越大）

关于内存，你真正需要关注的是：

  • 容量：这是最重要的参数。2025 年，16GB 是基准线。如果预算允许，32GB 会让你的电脑在多年后仍然不过时。8GB 在 2025 年已经偏少——同时开 Chrome + VS Code + 微信就可能吃紧。

  • 是否可扩展：

    • LPDDR5/LPDDR5x：焊死在主板上，不可升级（常见于轻薄本和 MacBook）
    • DDR5 SO-DIMM：插槽安装，可自行升级（常见于游戏本和部分全能本）
    • 购买前看清楚！如果是焊接内存，买的时候就要买够。

  • 双通道 vs 单通道：两条 8GB 组成的 16GB（双通道）比一条 16GB（单通道）的性能高约 10–30%——特别是对核显性能影响巨大。有些低价笔记本会用单通道 16GB 来降低成本，这是一个需要注意的坑。

  • 频率：日常使用中，DDR5 4800MHz 和 DDR5 5600MHz 的实际差距很小（通常 < 5%）。不必为了"频率高几百"多花很多钱。

4. 硬盘（SSD）

示例：512GB PCIe 4.0 NVMe SSD

部分 含义
512GB 存储容量
PCIe 4.0 接口协议版本——决定了最大传输速度
NVMe 传输协议——比旧的 SATA 协议快 5–10 倍
SSD 固态硬盘（而非 HDD 机械硬盘）

你需要知道的实际差异：

类型 顺序读取速度 适合用途 2025年参考价（1TB）
SATA SSD ~550 MB/s 预算有限的旧电脑升级 ~350 元
PCIe 3.0 NVMe ~3500 MB/s 主流日常使用 ~400 元
PCIe 4.0 NVMe ~7000 MB/s 高性能需求、大文件读写 ~450 元
PCIe 5.0 NVMe ~12000 MB/s 极致性能（目前溢价较高） ~800 元

💡 容量建议：2025 年，1TB 起步是最理性的选择。操作系统 + 常用软件就要占 100GB 以上，加上课程资料、项目代码、偶尔的游戏，512GB 很快就捉襟见肘。1TB NVMe SSD 目前价格约 400–500 元，不贵。

5. 屏幕

示例：16 英寸 2560×1600 IPS 165Hz 100% sRGB

屏幕参数是最容易被忽视、但对日常体验影响巨大的部分：

参数 含义 怎么选
尺寸 屏幕对角线长度 14 寸便携，16 寸大屏舒适，二者折中选 15.6 寸
分辨率 像素点的数量 1920×1080(1080P) 是及格线；2560×1600(2.5K) 是目前主流；3840×2400(4K) 适合设计
面板类型 屏幕的显示技术 IPS（可视角度好、色彩准）、OLED（对比度极高、色彩艳丽但可能烧屏）、VA（适合高对比场景）
刷新率 屏幕每秒刷新几次 60Hz 是基础；120Hz 让滚动更流畅；165Hz/240Hz 是游戏需求
色域 能显示的颜色范围 100% sRGB 是标准线；P3 色域/100% DCI-P3 适合设计和影视
亮度 屏幕最亮程度（nit） 300nit 室内够用；400nit+ 适合户外或光线强的环境

一个生活化的理解：

如果把屏幕比作一面墙上的画：

  • 分辨率 = 这幅画用了多少种颜料的颗粒（颗粒越细，画面越精细）
  • 刷新率 = 这幅画每秒更新几次（更新越快，动态画面越流畅）
  • 色域 = 画家的颜料盘有多少种颜色（颜色越多，越接近真实世界）

⚠️ 关于 OLED 屏：OLED 的显示效果确实惊艳（深邃的黑色、鲜艳的色彩），但它有一个潜在风险——烧屏（屏幕长时间显示固定内容后留下残影）。如果你经常盯着 IDE 写代码或者盯着 Word 文档，OLED 的烧屏风险比看视频时要高。目前新一代 OLED 面板烧屏概率已大幅降低，但如果你用一台屏幕五六年，还是 IPS 更稳妥。

6. 电池

示例：80Wh

电池容量用 Wh（瓦时） 表示。简单理解：

$续航时间 \approx \frac{电池容量 (Wh)}{平均功耗 (W)}$

比如一台 80Wh 电池的笔记本，如果日常使用平均功耗约 8W，理论续航约 10 小时。

电池容量 典型续航（日常使用） 常见于
40–55Wh 4–7 小时 入门轻薄本、部分游戏本
60–75Wh 8–12 小时 主流轻薄本
80–100Wh 10–15 小时 高端轻薄本、MacBook

💡 注意：厂商标称的续航时间通常是在"极端省电"模式下测试的。实际使用中打八折甚至六折是常态。如果商品页写"续航 15 小时"，你预期 8–10 小时比较合理。

7. 接口

示例：2×USB-A 3.2、1×USB-C（雷电4）、1×HDMI 2.1、1×SD 卡槽

接口决定了你能插什么外设。2025 年最常见的接口类型：

接口 长什么样 能干什么 速度
USB-A 传统长方形 USB 口 U 盘、鼠标、键盘等 USB 3.2 最高 20Gbps
USB-C 小椭圆形，正反插 数据传输、充电、外接显示器（取决于协议） 取决于协议
雷电 4/5（Thunderbolt） 物理形状同 USB-C 高速数据 + 充电 + 外接显示器 + 外接 GPU 40/80 Gbps
HDMI 梯形接口 外接显示器/投影仪 HDMI 2.1 支持 4K 120Hz
SD 卡槽 半截信用卡大小的槽 读取相机 SD 卡 UHS-II 约 300MB/s
3.5mm 耳机孔 圆形小孔 有线耳机/麦克风 模拟信号

特别说明：USB-C 不等于雷电

这是最常见的接口混淆。USB-C 只是一个物理接口形状，插进去的线缆可能走的是 USB 2.0（480Mbps）、USB 3.2（10Gbps）、USB4（40Gbps）或雷电 4/5（40/80Gbps）。就像"一条公路"可以跑自行车也可以跑跑车——USB-C 口长得一样，但内部支持的协议决定了速度和功能。

买电脑时，如果你有需要外接高速设备或显示器，一定要看这个 USB-C 口支持什么协议，不要只看"有 USB-C 口"就觉得万事大吉。

📋 一张"参数优先级"速查表

不是所有参数都同等重要。根据不同的使用场景，你应该优先关注不同的指标：

使用场景 最重要 其次 锦上添花
日常学习/办公 内存容量 ≥ 16GB、SSD ≥ 512GB 屏幕分辨率 ≥ 2K、续航 ≥ 8h CPU 级别、接口数量
编程开发 内存 ≥ 16GB（最好 32GB）、SSD ≥ 1TB CPU 多核性能、屏幕分辨率 键盘手感、接口丰富度
游戏 GPU 型号和功耗释放 屏幕刷新率 ≥ 120Hz、CPU 不拖后腿 散热设计、键盘 RGB
深度学习/AI GPU 显存 ≥ 8GB（最好 12GB+） 内存 ≥ 32GB、SSD ≥ 1TB GPU 架构（支持 CUDA 的 NVIDIA 卡）
设计/视频剪辑 屏幕色域 ≥ 100% sRGB GPU + 内存、SSD 速度 屏幕亮度、色准

❌ 常见误区

❌ "CPU 主频越高越好" → ✅ 主频只是性能的一个维度。架构、核心数、缓存大小同样重要。一颗 4.0GHz 的旧架构 CPU 可能打不过一颗 3.5GHz 的新架构 CPU（第二章讲过的 IPC 概念）。

❌ "512GB 硬盘足够了" → ✅ 2025 年，一个操作系统就要 40GB+，常用软件（Office、IDE、浏览器、Adobe）加起来轻松超过 50GB，再加上课程资料、项目文件、偶尔下载的游戏……512GB 很快会用完。1TB 才是 2025 年的"够用线"，况且 1TB SSD 的价格已经降到大约 400–500 元。

❌ "DDR5 一定比 DDR4 好" → ✅ 在同一平台下 DDR5 确实更快，但如果你在二手市场/预算有限的情况下选择上一代 DDR4 平台，DDR4 3200MHz 配合合适的 CPU 依然完全够用。不要为了追求内存代数而选择了一个整体配置更差的机器。

❌ "刷新率越高越好，165Hz 比 60Hz 好两倍" → ✅ 刷新率的提升是递减效应。从 60Hz → 120Hz 的改善非常明显（你能肉眼感觉到丝滑），但从 120Hz → 165Hz 的差异就不大了，240Hz → 360Hz 更是只有职业电竞选手才能感知。如果你不玩竞技游戏，120Hz 完全足够。

🔧 动手环节：拆解你自己电脑的参数

现在，让我们用你自己的电脑来练手。

Windows 用户：

  1. 按下 Win + R，输入 dxdiag，回车。
  2. 你会看到 DirectX 诊断工具，包含以下信息：
    • 系统标签页：CPU 型号、内存容量、操作系统版本
    • 显示标签页：GPU 型号、显存大小、驱动版本
  3. 查看硬盘信息：
    • 按 Win + R，输入 diskmgmt.msc，打开磁盘管理
    • 你能看到每块硬盘的容量和分区情况

或者用命令行获取更完整的信息：

# 查看 CPU 信息
Get-CimInstance -ClassName Win32_Processor | Select-Object Name, NumberOfCores, MaxClockSpeed

# 查看内存信息
Get-CimInstance -ClassName Win32_PhysicalMemory | Select-Object Manufacturer, Capacity, Speed, MemoryType

# 查看硬盘信息
Get-CimInstance -ClassName Win32_DiskDrive | Select-Object Model, Size, MediaType

# 查看显卡信息
Get-CimInstance -ClassName Win32_VideoController | Select-Object Name, AdapterRAM, DriverVersion

Mac 用户：

# 查看完整硬件信息
system_profiler SPHardwareDataType

# 查看硬盘信息
diskutil list

# 查看显卡/GPU 信息
system_profiler SPDisplaysDataType

练习：对照你的输出结果，回答以下问题：

  1. 你的 CPU 是什么型号？属于 i 几/Ryzen 几？后缀是什么？
  2. 你的内存有多大？是 DDR4 还是 DDR5？
  3. 你的硬盘是 SSD 还是 HDD？容量多大？
  4. 你有独立显卡吗？如果有，是什么型号？

✅ 本节要点

  • ✓ CPU 型号中的后缀字母（U/H/HX/K/F）决定了功耗和性能定位
  • ✓ 显卡的"Laptop vs Desktop"和功耗释放值比型号名更重要
  • ✓ 内存关注容量 > 是否可升级 > 双通道 > 频率
  • ✓ 硬盘优先保证容量（≥1TB），NVMe PCIe 3.0 及以上速度都够用
  • ✓ 屏幕选购按场景优先排序：分辨率 > 色域 > 刷新率 > 面板类型
  • ✓ USB-C ≠ 雷电，接口的协议比形状更重要

📐 核心概念：三种购买渠道的本质区别

品牌整机（笔记本 & 品牌台式机）

什么是品牌机？ 联想、戴尔、惠普、华硕、华为、苹果等厂商出售的完整电脑产品，开箱即用。

优势：

  1. 省心：硬件兼容性由厂商保证，不会出现"CPU 和主板不匹配"的问题
  2. 售后保障：全国联保，通常 1–3 年。出了问题打售后电话就行，有些品牌甚至提供上门维修
  3. 笔记本的唯一选择：你不可能"自己组装一台笔记本"——笔记本的模具、散热、主板都是定制的
  4. 预装系统：出厂自带正版 Windows（或 macOS），省去了安装和激活的麻烦

劣势：

  1. 品牌溢价：你在为品牌名声、售后体系、营销成本买单。同样的硬件配置，品牌台式机通常比自己组装贵 15–30%
  2. 配置不灵活：厂商给什么配置你就得接受什么。想要 32GB 内存 + 512GB 硬盘的组合？对不起，这个型号只有 16GB + 1TB
  3. 台式品牌机的隐藏坑：某些低价品牌台式机会使用"缩水"硬件——比如用功率不足的电源、用 OEM 版无法升级的主板、用慢速内存条。这些在参数表上不一定能看出来

自己组装（DIY 台式机）

什么是 DIY 装机？ 自己选购每一个零件（CPU、主板、内存、硬盘、显卡、电源、机箱、散热器），然后像拼乐高一样组装起来。

优势：

  1. 性价比最高：没有品牌溢价，同样的预算能获得更强的性能。7000 元的 DIY 台式机，性能可能超过 10000 元的品牌游戏本
  2. 完全自由定制：你可以根据自己的需求精确配置——编程用途就把钱花在 CPU 和内存上，游戏用途就把钱花在显卡上
  3. 升级方便：任何一个部件不满意了，以后单独换掉就行。不像笔记本或品牌机很多部件焊死了
  4. 学习硬件知识：装机过程本身就是对前四章知识的最佳实践

劣势：

  1. 需要学习成本：你需要了解兼容性（CPU 和主板的接口是否匹配、电源功率是否足够、机箱能否装下显卡……）
  2. 售后分散：每个零件的保修由各自的品牌负责。出了问题你需要判断是哪个部件的问题，然后联系对应的厂商
  3. 只适用于台式机：你没法组装笔记本
  4. 有"翻车"风险：新手可能遇到接线错误、散热安装不当等问题（不过现在有大量视频教程可以参考，风险已经很低）

二手电脑

什么是二手？ 在闲鱼、转转等二手交易平台购买别人用过的电脑。

优势：

  1. 价格低：一台发布 1–2 年的高配笔记本，二手价通常只有原价的 50–70%
  2. 高配低价：用 5000 元的预算可能买到原价 10000 元级别的配置

风险：

  1. 硬件暗病：电池损耗、屏幕老化、散热硅脂干涸、硬盘寿命接近极限……这些在外观上看不出来
  2. 无保修：二手交易通常没有售后保障，出了问题只能自己修
  3. 配置造假：不良商家可能刷改 BIOS 信息，让 i5 看起来像 i7
  4. 货源不明：可能是矿机、泡水机、翻新机

如果你决定买二手，务必做到以下几点：

购买前：

  1. 查清楚目标型号的全新价格和典型二手价格，如果卖家报价低于市场价 30% 以上，要高度警惕
  2. 优先选个人卖家（学生毕业换机等），远离从未见面的"专业二手商"
  3. 坚持走平台付款，拒绝任何私下转账

验机清单（验机工具准备一个 U 盘，装好"图吧工具箱"）：

检查项 怎么查 关注点
CPU/GPU 真伪 CPU-Z、GPU-Z 型号是否与描述一致
硬盘健康 CrystalDiskInfo 通电时间、健康状态、坏道数
屏幕坏点 DisplayX 或在线纯色测试网页 纯色背景下有无亮点/暗点
电池健康 powercfg /batteryreport（Windows） 设计容量 vs 当前完全充电容量，健康度 > 80%
内存真伪 CPU-Z 的 Memory 标签页 容量、频率、品牌是否与描述一致
外观 肉眼检查 边角磕碰、铰链松动、螺丝拧痕
接口 逐个测试 所有 USB、HDMI、耳机孔是否正常
稳定性 AIDA64 或 FurMark 烤机 15 分钟 是否出现蓝屏、死机、花屏、自动关机 
# Windows 查看电池健康度报告
powercfg /batteryreport /output "%USERPROFILE%\Desktop\battery-report.html"
# 运行后会在桌面生成一个 HTML 文件，用浏览器打开查看

⚠️ 烤机测试是最关键的一步。很多暗病（修过的主板、散热失效）在正常使用时不会暴露，但在 CPU/GPU 满载 15–20 分钟后就会"原形毕露"——如果出现蓝屏、自动关机或温度直冲 100°C 以上，果断放弃。

二手 MacBook 的特殊注意事项：

  • 检查是否解除了激活锁（iCloud 锁）——如果没解，你永远无法正常使用
  • 查看电池循环次数：「关于本机」→「系统报告」→「电源」→「循环计数」，建议 ≤ 500 次
  • Apple Silicon 的 Mac 所有核心部件焊死，维修成本极高，务必仔细验机

❌ 常见误区

❌ "品牌机都有品牌税，不值得买" → ✅ 笔记本市场中，品牌溢价已经被激烈竞争压得很低了。一台 5000 元的品牌轻薄本包含了设计、散热、屏幕、售后等综合体验，这不是简单的"硬件堆砌"能替代的。品牌溢价在台式机上更明显，但在笔记本领域并不严重。

❌ "组装电脑很难，一定会翻车" → ✅ 2025 年的 DIY 装机已经非常标准化了。CPU 有防呆设计（放反了装不进去）、内存条只能单方向插入、各种线缆接口都有明确标识。看一遍 B 站教程，大部分人第一次装机就能成功。

❌ "二手电脑不靠谱，千万别买" → ✅ 二手市场确实鱼龙混杂，但如果你学会了验机流程、选择靠谱的卖家、走平台保障，完全可以用很低的价格买到好机器。关键是你得具备判断力——而这正是前四章教给你的。
